プライバシーポリシー

「すーちゃん」（作者が自分の家で使う AI ペット）が Google のユーザーデータをどう扱うかを書きます。

使う人

作者本人だけです。ほかの人に使わせることはありません。

求める権限

Google ドライブの https://www.googleapis.com/auth/drive.file だけです。すーちゃんが作ったファイルと、作者が選んで開いたファイルにだけ触れます。ほかのファイル、メール、連絡先などには触れません。

データの使い道

  • 作者に声で頼まれたときに、スプレッドシート・ドキュメント・スライドを作る、追記する、読むためだけに使います
  • 読んだ内容は、家のサーバーの中で作者への返事を作るのに使います
  • Google のユーザーデータを第三者に渡したり、売ったり、広告に使ったりしません。AI モデルの学習にも使いません

保存

Google から受け取る更新トークンは、作者の家のサーバーにだけ保存し、作者のほかは読めないようにしています。

Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の使用と、ほかのアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

取り消し

Google アカウントの「サードパーティ製のアプリとサービス」 から、いつでもアクセスを取り消せます。
